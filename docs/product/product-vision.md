# 제품 비전

## 한 문장 정의

Oh My Feed는 신뢰하는 정보원에서 오늘 볼 것을 추리고, 사람이 유용하다고 판단한 지식을 프로젝트와 AI에 안전하게 연결하는 **Personal AI Learning Feed**다.

## “거인의 어깨”에서 이어받은 철학

새로운 지식은 진공에서 생기지 않는다. 좋은 원문을 발견하고, 내 맥락에서 의미를 판단하고, 실제 일에 적용할 때 비로소 다음 생각의 발판이 된다. Oh My Feed는 이 과정을 다음 루프로 만든다.

`발견 → 판단 → 연결 → 승인 → 학습 → 활용`

여기서 “학습”은 모델을 자동 재훈련한다는 뜻이 아니다. 사용자가 승인한 근거 있는 지식 카드를 개인 AI가 다시 찾고 사용할 수 있게 만드는 것이다.

## 해결하려는 일

정보가 부족한 것이 아니라 처리 과정이 끊겨 있다.

- 여러 공식 블로그, 릴리스, 뉴스레터를 반복 방문한다.
- 같은 소식을 여러 채널에서 다시 읽는다.
- 읽음, 저장, 무관심 상태가 도구별로 흩어진다.
- 좋은 정보가 실제 프로젝트 결정으로 이어지지 않는다.
- AI가 검토한 것과 사람이 읽은 것을 구분하기 어렵다.

## 제품 원칙

1. **줄이는 것이 먼저다.** 더 많은 콘텐츠가 아니라 오늘 처리할 5~10개를 만든다.
2. **요약보다 맥락이다.** 무엇을 말하는지보다 왜 내 프로젝트에 중요한지를 설명한다.
3. **AI는 제안하고 사람이 확정한다.** 자동 생성 지식은 승인 전까지 후보일 뿐이다.
4. **상태와 권한을 분리한다.** AI가 검토해도 사용자의 읽음 상태는 바뀌지 않는다.
5. **출처를 잃지 않는다.** 모든 설명과 학습 지식은 원문으로 돌아갈 수 있어야 한다.
6. **개인화를 가장하지 않는다.** 사용자 맥락이 없으면 일반 피드를 제공하고, 관심사나 프로젝트가 있을 때만 맞춤 기준과 관련도를 표시한다.

## 피드 상태

| 상태 | 구성 | 제품이 설명해야 할 것 |
|---|---|---|
| 둘러보기 | 공식 업데이트, 도구와 제품, 연구와 논문, 개발 가이드 | 무엇이 새로 나왔는가 |
| 내 피드 | 프로젝트 및 관심 주제와 관련된 항목 | 왜 나와 관련 있는가, 어떤 기준을 사용했는가 |

일반 피드에는 관련도 점수나 “당신을 위해 골랐다”는 표현을 사용하지 않는다. 내 피드에는 프로젝트명, 맞춤 기준, 관련 근거를 함께 보여준다.

## 포지셔닝

| 단순 RSS/AI 리더 | Oh My Feed |
|---|---|
| 새 글을 모은다 | 오늘 볼 것을 줄인다 |
| 내용을 요약한다 | 프로젝트 영향을 설명한다 |
| 북마크한다 | 승인된 지식으로 구조화한다 |
| AI가 사용자 대신 결정한다 | AI가 제안하고 사람이 확정한다 |
| 읽고 끝난다 | 개인 AI가 이후 업무에서 활용한다 |

## 초기 사용자

공식 AI/개발 소스 여러 개를 매일 확인하며, 동시에 한 개 이상의 실제 프로젝트를 진행하는 개인 개발자와 빌더. 팀 협업 기능보다 개인이 반복해서 쓰는 처리 루프를 먼저 검증한다.
